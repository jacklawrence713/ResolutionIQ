User Manual

Complete guide for loss mitigation specialists, supervisors, and administrators using the ResolutionIQ Loss Mitigation Rules Engine.
Version 1.0 · March 2026 · For Authorized Users Only

Quick Start

ResolutionIQ evaluates a mortgage loan against all eligible loss mitigation options across 5 investors (FHA, Fannie Mae, Freddie Mac, VA, USDA) and returns a ranked list of eligible options with documentation checklists and regulatory citations — in under 2 seconds.

Basic workflow: Log in → Dashboard → New Case → Enter loan data (Inputs tab) → Evaluate → Review results (Results tab) → Review reasoning (Audit tab) → Generate report → Save case.

1Dashboard

The Dashboard is your case management hub. It loads by default when you log in.

Case List

Each row represents one loan evaluation case. Columns include: loan number, borrower name, investor, assigned specialist, evaluation date, SLA deadline, and status.

  • SLA badge colors: Green = on track · Yellow = <5 days remaining · Red = overdue
  • Status flags: Draft, Evaluated, Under Review, Completed, Escalated

Search & Filter

Use the search bar to find cases by loan number or borrower name. Filter by investor, assigned user, status, or date range using the filter panel.

New Case

Click + New Case to open a blank evaluation form. You can also import loan data from a JSON or LOS export.

Tip: Assign cases to specialists from the Dashboard case menu. Assigned users receive an in-platform notification and the case appears in their personal queue.

2Inputs

The Inputs tab is where you enter all loan and borrower data before running an evaluation. Fields are organized into sections matching the natural flow of a loss mitigation interview.

Data Completeness Score

A percentage score in the top-right corner shows how complete the required fields are. The score is color-coded: green ≥80%, yellow 60–79%, red <60%. Running an evaluation with a low completeness score may produce incomplete results.

Investor Selection

Select the investor (FHA, FNMA, FHLMC, VA, USDA) from the dropdown at the top. Selecting an investor will show or hide fields relevant to that investor's guidelines. If you are unsure of the investor, check your servicing system — it is typically identified in the loan's investor fields.

Selecting the wrong investor will produce incorrect eligibility results. Always confirm the investor before evaluating.

Key Input Sections

Loan Identification

  • Loan Number — your internal or servicer loan number
  • Borrower Name — primary borrower for file identification
  • Note Date / First Payment Date — used to compute loan age (critical for eligibility)
  • Original Term / Note Term — original loan term in months (typically 360)

Loan Financials

  • UPB — current unpaid principal balance
  • Original UPB — balance at origination (used for MTMLTV calculations)
  • Current Interest Rate — existing note rate as a percentage (e.g., 6.75)
  • PMMS Rate — current Freddie Mac Primary Mortgage Market Survey weekly average rate; used to compute target modification rates for all investors. Update this weekly.
  • Current P&I — current principal and interest payment
  • Current PITI — total monthly payment including escrow
  • Gross Monthly Income — total household gross monthly income

Delinquency & Status

  • Delinquency Months — number of payments past due
  • Hardship Type — select the borrower's hardship from the dropdown (income reduction, job loss, medical, divorce, etc.)
  • Hardship Duration — short-term (<6 months), long-term (6+ months), or resolved
  • Occupancy Status — primary residence, secondary, investment. Most retention options require primary residence.
  • Foreclosure Active — toggle if active foreclosure proceedings are underway

Arrears & Escrow

  • Arrearages to Capitalize — total P&I arrears eligible for capitalization
  • Escrow Shortage — escrow deficiency amount
  • Escrow Advance Balance — amount of escrow advances made by servicer
  • Legal Fees, Late Fees — fees eligible for capitalization under applicable guidelines
  • Suspense Balance — any funds held in suspense to offset capitalization
  • Prior Partial Claim Balance — FHA only; outstanding prior partial claim UPB

Quick LOS Import

Use the Quick LOS Import button to paste or upload a JSON export from your LOS. The engine will automatically map known field names from Encompass, BytePro, and other common systems. See the LOS Field Mapping Guide for field name reference.

3Results

After clicking Evaluate (or pressing Ctrl+Enter), results appear on this tab. Options are listed in the investor's preferred waterfall evaluation order.

Reading the Results

  • Eligible options — shown with a green checkmark, listed first in waterfall order
  • Ineligible options — shown with a red X, with the primary failure reason
  • Approval Terms — click any eligible option to expand its calculated terms: new rate, new payment, capitalized amount, forbearance amount, partial claim amount, etc.
  • Doc Checklist — each eligible option includes a dynamically-generated required documentation checklist per investor guidelines
  • Regulatory Citation — each determination cites the specific Mortgagee Letter, Guide section, CFR, or Bulletin that governs it
The Results tab shows the recommended option at the top of the eligible list, but the Servicer retains full discretion in selecting which option to pursue. Investor submission procedures and borrower preferences must also be considered.

4Audit

The Audit tab provides a node-by-node view of every eligibility criterion evaluated for every option. This is your exam-ready documentation of the evaluation reasoning.

Reading the Audit Trail

  • Pass (green) — criterion met; shows the specific value and the rule it was compared against
  • Fail (red) — criterion not met; shows why and the specific guideline citation
  • Nodes — each criterion is a "node" — a question the engine asks, the answer it found in the input data, and whether the answer passes the rule
Tip: The Audit tab is your primary documentation for regulatory exams and investor reviews. It provides more detail than a manually-written loss mitigation decision memo and is already formatted for file retention.

Example Audit Nodes (FHA 40-Year Combo)

  • Loan age ≥ 12 months? → Yes (Note Date: 01/15/2022, 38 months ago) → PASS
  • Delinquency 4–12 months? → Yes (4 months DLQ) → PASS
  • No active foreclosure? → Correct → PASS
  • Hardship documented? → Yes (income reduction) → PASS
  • Prior mod cooldown (24 months)? → No prior mod → PASS
  • P&I reduction achievable ≥25%? → Yes (new rate 6.50% PMMS+0.25% achieves 31% reduction) → PASS
  • Partial claim headroom available? → Yes (prior PC $0 + new cap < $45,000 FMV limit) → PASS

5Report

The Report tab generates a formatted, print-ready evaluation report for file retention and borrower communication support.

Report Sections

  • Loan identification summary
  • Eligible options list with approval terms and regulatory citations
  • Ineligible options with primary failure reason
  • Evaluation timestamp and Authorized User attribution

AI Underwriting Assistant

The report tab includes an optional AI assistant powered by the Claude API. Enter your Claude API key in Settings (key is not stored by ResolutionIQ). Use the assistant to analyze edge cases, draft borrower communication language, or get a plain-language explanation of a complex eligibility determination. The assistant has context about the current loan's evaluation.

AI assistant output is analytical support only and does not constitute a loss mitigation determination, legal advice, or regulatory guidance.

6Compare

The Compare tab allows side-by-side evaluation of two loans. Load two cases from your case history or enter two sets of loan data manually. Useful for portfolio triage, training scenarios, and supervisor review of borderline cases.

7Portfolio

The Portfolio tab supports bulk CSV upload for evaluating multiple loans simultaneously.

CSV Format

Your CSV should include one row per loan with column headers matching ResolutionIQ field names or common LOS export names. Refer to the LOS Field Mapping Guide for column name reference. Required minimum fields: loanNumber, loanType, upb, currentInterestRate, delinquencyMonths, hardshipType, grossMonthlyIncome.

Portfolio Results

After upload, a results grid shows each loan with: investor, eligible option count, top eligible option, and a summary status. Click any row to open the full evaluation. Export the results grid to Excel or CSV for pipeline reporting.

Tip: Use the Portfolio tab at month-start to triage your entire delinquent pipeline and prioritize outreach based on available retention options.

8Settings

Profile

Update your name, email, and password. Set your default investor preference if your team primarily services one investor type.

Servicer Overlays

Admin users can configure servicer-level overlays that sit on top of investor minimum standards:

  • Minimum FICO floor — reject options below a servicer-set credit score
  • Maximum DLQ months — exclude options above a certain delinquency threshold
  • Excluded hardship types — remove options for specific hardship categories
  • Excluded options — turn off specific options your servicer does not offer
Overlays are applied globally to all evaluations for your servicer. Changes take effect immediately. Only admins can modify overlays.

Database Setup (Admin)

If you are setting up ResolutionIQ for the first time, use the DB Setup button in Settings to generate and run the required Supabase SQL. See the Admin Setup Guide for complete instructions.

User Management (Admin)

Admins can approve or deny new user registrations, change user roles (specialist, supervisor, admin), and deactivate users who have left the organization. New users who self-register are placed in "Pending" status and cannot access the platform until approved.
