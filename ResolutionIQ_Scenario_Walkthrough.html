Cross-Scenario Observations
Disaster vs. Standard Pathways

Scenarios 3, 4, and 5 illustrate how disaster hardship flags override or redirect standard eligibility paths. Each investor has distinct entry criteria — FHLMC requires a dual DLQ gate under Bulletin 2026-2; VA requires ongoing hardship and prior forbearance; USDA routes to non-disaster modifications when no disaster designation exists.

Imminent Default Gate (FNMA)

Scenario 2 demonstrates that DLQ=0 does not preclude modification eligibility under FNMA when imminent default is properly documented per D2-3.2-06. The engine applies all three ID rules in sequence and routes to the Flex Mod ID path when any qualifying rule passes.

FHA Partial Claim Cap Monitoring

Scenario 1 highlights the importance of tracking the 30% original UPB partial claim ceiling ($63,000 cap for Santos). The engine validates capitalized balance against this limit before recommending the 40-year combo path as an alternative.

USDA MRA Subordination Structure

Scenario 5 shows the engine's Step 3 deferral logic: when capitalization alone cannot resolve the payment gap, the MRA subordinate lien path is triggered. The 36-payment performance requirement and 30% cap are hard constraints validated before the combo option is presented.
