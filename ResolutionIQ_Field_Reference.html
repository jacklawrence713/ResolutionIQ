Engine behavior with missing data: Fields left blank are treated as their default value (shown in the "Valid Values / Default" column). Boolean fields default to false unless noted otherwise. Numeric fields default to 0. Missing critical fields (e.g., DLQ months, UPB) will result in most options being ineligible — always populate the core financial and delinquency fields for a meaningful evaluation.
Investor-specific fields: Fields prefixed with fnma, fhlmc, usda, or va only affect the named investor's evaluation. Common fields (no prefix) affect all investors. When evaluating a loan, populate the common fields plus the investor-specific section matching the loan's investor.

Section 3 — Delinquency Fields

DLQ measurement · Prior workout history · All investors

DLQ is the most critical eligibility driver. Every investor has DLQ floor and ceiling thresholds for each option. Always populate both delinquencyMonths and delinquencyDays for precise evaluation — the engine uses months for most tests and days for USDA informal forbearance (360-day cap).
Field NameUI LabelDescription & Eligibility ImpactTypeReq?Values / Default
delinquencyMonthsDLQ (Months) Number of months the loan is delinquent (missed payments). Primary DLQ input for all eligibility tests. Key thresholds by investor:
  • FHA: 0 = Reinstatement only; 3–12 = Deferral; any = Mod; ≥12 = Forbearance/Repayment blocked
  • USDA: 0 = Reinstatement only; ≥1 = Repayment; ≥3 = Streamline Mod (90d); ≤12 = Special Forbearance
  • VA: ≥1 = Reinstatement; ≥2 (30d) = Repayment; ≥3 (61d) = Modification
  • FNMA: 2–6 = Payment Deferral; 2–12 = Standard Flex Mod; ≥3 = Streamlined; 0 with ID = Flex Mod
  • FHLMC: 2–6 = Payment Deferral; 2+ = Standard Flex Mod; ≥3 = Streamlined; ≥3 disaster eval = Disaster Flex Mod

Affects: USDA — Informal Forbearance cap; VA — 61-day modification floor; FHLMC — Disaster Flex Mod evaluation-date gate		 NumberConditionalInteger days.
